# HUSH 1.0

## Summary
HUSH 1.0 brings the product into a coherent release shape: an AI assistant for macOS that can chat, listen, capture context, and stay discreet when needed.

## Highlights
- Unified overlay and app window experience
- Clearer settings with less noise and better defaults
- More reliable provider, session, and permission behavior

## AI & Providers
- Stable external provider setup and model selection
- Clear distinction between provider connection, model behavior, and assistant defaults
- Protected account changes and saved-key reveal with Touch ID or password
- First-party provider status documented clearly for the release

## Live, Text, and Capture
- Live mode feels dependable for real interaction
- Text mode remains the steady default for general AI work
- Capture mode bridges visual context into the assistant more cleanly

## Stealth & Privacy
- Stealth is integrated into the product identity, not hidden as an afterthought
- Privacy-sensitive and screen-visibility-sensitive defaults are more deliberate

## Fixes
- Reduced settings clutter without changing the current navigation model
- Improved consistency of terminology across the app and documentation
