# HUSH Release Notes Template

## Summary
State what this release makes better in one short paragraph. Keep the tone polished, concise, and product-led.

## Highlights
- Highlight the most meaningful user-visible improvements
- Keep this focused on what changed in the experience
- Avoid low-level implementation detail here

## AI & Providers
- Note provider setup, model selection, routing, or intelligence behavior changes
- Mention whether the release changes mock-only behavior or restores a real integration path

## Live, Text, and Capture
- Describe the most important mode improvements
- Call out any behavioral changes that users or testers should notice

## Stealth & Privacy
- Describe visibility, screen-presence, privacy, or permission-related improvements
- Mention behavior changes that alter discretion or discoverability

## Fixes
- List important fixes in concise language
- Focus on behavior, reliability, and clarity

## Known Issues
- Call out active limitations or rough edges
- Prefer short, direct statements

## Notes for Internal Review
- Add rollout caveats, testing focus, or follow-up tasks if needed
