# HUSH 0.3 Live and Stealth

## Summary
This milestone sharpens HUSH's most distinctive behaviors: Live mode and stealth. The app should feel faster during spoken interaction and quieter when discretion matters.

## Highlights
- Improved Live-mode clarity and timing
- Refined stealth behavior and visibility defaults
- Better aligned overlay behavior with discreet usage

## AI & Providers
- Maintained provider-backed response generation while focusing product work on real-time use cases

## Live, Text, and Capture
- Improved handling of microphone and system-audio listening paths
- Refined transitions from listening to answer generation
- Tightened the relationship between quick capture and overlay actions

## Stealth & Privacy
- Reduced system-surface visibility where supported
- Improved the relationship between stealth settings, screen presence, and notification behavior

## Fixes
- Reduced noise in stealth-related settings
- Improved defaults for common discreet-use scenarios

## Known Issues
- Behavior across all macOS display and sharing setups still needs verification
- Some stealth controls may still be more granular than necessary

## Notes for Internal Review
- QA should focus on shared-screen scenarios, Mission Control behavior, screen capture visibility, and spoken-interaction reliability
